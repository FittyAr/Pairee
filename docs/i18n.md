# Adding a UI language

Pairee loads TOML files from `lang/` (next to the binary, or the config `lang/`
folder). English is the fallback; Spanish ships in-tree.

## Files

| File | Role |
|------|------|
| `lang/en.toml` | Source of truth for keys |
| `lang/es.toml` | Spanish; **must have the same keys** as `en.toml` |
| `docs/i18n.md` | This guide |
| `scripts/check_translations.py` | `cargo xtask lint` and CI: valid TOML, same keys and placeholders in every language, no `t("key")` without its key, a `help_title_<page>` per help page; `--unused` lists keys no source file names |

## Add a language

1. Copy `lang/en.toml` to `lang/<code>.toml` (e.g. `fr.toml`).
2. Set `language_name` at the top (`"Français"`). That string is what the
   Settings language picker shows.
3. Translate every value under `[translations]`. Keep `{}` placeholders.
4. Do **not** add or remove keys. Run:

   ```bash
   python scripts/check_translations.py
   ```

   That check also runs in `cargo xtask lint` (the pre-push hook) and in
   `.github/workflows/check.yml`. It needs Python 3.11 or newer.

5. Load it in Settings → Plugins tab → Language (the list is discovered at
   runtime from `*.toml` files).

## Rules

- User-facing strings go through `crate::config::localization::t("key")`.
- Insert new keys in **both** `en.toml` and `es.toml` (alphabetically).
- F-key bar labels stay short (about 6 characters) so they fit the footer.
