# Lua API v1.x (current **1.2.0**)

Stability: **Stable** unless marked *Preview*. Removing or renaming a Stable
entry is a **MAJOR** bump.

| Binding | Kind | Notes |
|---------|------|--------|
| `pairee._lua_api_version` | string | `"1.2.0"` |
| `pairee._secure_mode` | bool | Host secure mode (informational; overwriting it has no effect) |
| `pairee.settings` | table | Manifest defaults + user overrides |
| `pairee.t(key, vars?)` | function | Plugin i18n |

| `pairee.th` | table | `name` + one `ui.Style` per theme color (`*_bg` keys set the background) |

`pairee.image`, `pairee.rt` and `pairee.th` are built on first access.

### Plugin methods and annotations

| Method | Called | Returns |
|--------|--------|---------|
| `setup(opts)` | once, after `main.lua` | — |
| `entry(args)` | the plugin's command runs | — |
| `peek(job)` | the Quick View shows a file | a widget, or `nil` to decline |
| `preload(job)` | before `peek`, and for the next 3 files | `complete[, err]` |
| `seek(job)` | PgUp / PgDn on the plugin's preview | new `skip` |

`job` = `{ file = File, area = {x, y, w, h, width, height}, skip, units? }`.
Every method runs asynchronously (may await dialogs, `sync`, `sleep`,
`Command`). `--- @since <api>` refuses to load on an older Lua API;
`--- @sync entry|peek|preload|seek` refreshes `pairee.cx` before the call.

## Context (`pairee.cx`)

Filled on each `pairee.sync`. Before the first sync, tables exist with empty cwd.

| Path | Type |
|------|------|
| `cx.active.cwd` | string |
| `cx.active.hovered` | `File` or `nil` |
| `cx.active.selected` | `File[]` |
| `cx.active.current.cwd` / `.hovered` | same as active |
| `cx.left.cwd` / `cx.right.cwd` | string |

`File` fields: `name`, `path`, `url`, `size`, `is_dir`, `is_symlink`, `mime`, `mtime` (unix seconds or `nil`), `is_hidden`, `is_exec`, `cha` (`Cha`).  
`tostring(file)` is `path`. `file == other` compares paths.

Throwing on error (same as 0.7), except `cha`. Paths are strings, `File`, `Path` or local `Url`.

| Binding | Notes |
|---------|--------|
| `read` / `write` / `exists` | Existing |
| `stat` / `file` | `File` userdata (`stat` is `nil` if missing) |
| `list` / `read_dir` | `File[]` |
| `mkdir(kind, path)` | `"dir"` or `"dir_all"` |
| `remove(kind, path)` | `"file"`, `"dir"`, `"dir_all"`, `"dir_clean"` |
| `rename(from, to)` | |
| `copy(from, to)` | returns bytes copied |

## `pairee.Command` (trusted)

```lua
pairee.Command(prog):arg(s|list):cwd(path):env(k,v)
    :stdin(PIPED|NULL|INHERIT):stdout(...):stderr(...)
    :spawn() | :output() | :status()
```

`Child`: `id`, `write_all`, `read`, `read_line`, `close_stdin`, `wait`,
`wait_with_output`, `try_wait`, `start_kill`.

Untrusted plugins cannot spawn. Trusted plugins outside Secure Mode are
unrestricted. In **Secure Mode** the same rules apply to `pairee.Command` and
`pairee.fs.spawn` (allowlist):

- `prog` must be a bare name (no `/`, `\`, drive or relative path) that the
  plugin declares in `manifest.toml`:

  ```toml
  [permissions]
  commands = ["git", "rg"]
  ```

- It is resolved through the absolute entries of `PATH` (on Windows only
  `.exe` / `.com`; `.bat` / `.cmd` are never resolved) and the resolved
  absolute path is executed.
- Shells, interpreters, network clients and command wrappers (`sh`, `bash`,
  `cmd`, `powershell`, `python*`, `node`, `curl`, `env`, `xargs`, ...) are
  always refused, even when declared and even when a declared name is a
  symlink to one of them.
- `Command:env(name, value)` only accepts `LANG`, `LANGUAGE`, `LC_*`, `TERM`,
  `COLORTERM`, `NO_COLOR`, `CLICOLOR`, `CLICOLOR_FORCE`, `FORCE_COLOR`, `TZ`,
  `COLUMNS` and `LINES`; `Command:cwd(path)` must be an existing folder inside
  the plugin's `pairee.fs` read jail.
- Any violation raises a Lua error starting with `Security violation:`.

## App / emit / utils / UI

| Binding | Notes |
|---------|--------|
| `pairee.app.cwd/cd/focus/set_focus/notify/hovered` | Legacy app table |
| `pairee.emit(action, args)` | `cd`, `set_focus` / `focus`; untrusted plugins: navigation/view/sort/selection actions and their own commands only; args must be dense lists or string-keyed maps (≤ 32 levels, ≤ 100 000 values) |
| `pairee.file_cache({file, skip})` | Preview cache path |
| `pairee.utils.target_os/family/time/hash/quote` | |
| `pairee.utils.percent_encode/decode` | |
| `pairee.utils.json_encode/decode` | *Preview*; same limits as `emit` args (refused values → `nil`) |
| `pairee.utils.sleep(secs)` | *Preview* (async) |
| `pairee.ui.*` | Widget userdata: `Style`, `Span`, `Line`, `Text` (`Text.parse` ANSI), `Paragraph`, `List`, `Table` / `Row`, `Gauge`, `Border`, `Layout`, `Constraint`; `Align`, `Wrap`, `Edge`. 1.0 constructor forms and `{type = ...}` tables still accepted. At most 100 000 nodes / 8 MiB of text |
| `pairee.clipboard(text?)` | Read: trusted plugins outside Secure Mode only (`PermissionDenied` otherwise). Write: every plugin, control characters except tab/LF removed, at most 1 MiB |
| `pairee.utils.uid/gid/user_name/group_name/host_name` | `nil` where the platform has none (ids and group on Windows) |
| `pairee.image.show(path)` | Image widget; the host decodes the file (Quick View size cap) |
| `pairee.image.info(path)` | `{w, h, format, color}` |
| `pairee.image.precache(src, dst, opts?)` | PNG thumbnail (`max_width` / `max_height`, default 1024) |
| `pairee.preview_code({file, skip?, lines?})` | Opaque paragraph: text with line numbers, highlighted like the viewer (setting `syntax_highlighting`, theme colors), at most 5000 lines |
| `pairee.preview_widget({file?, skip?}, widget)` | Show a widget in the Quick View later (only while it shows that file) |

`image.show`, `image.info` and `preview_code` accept the file being previewed
(the current `peek` / `preload` / `seek` job) or what the `pairee.fs` read jail
allows; `image.precache` only the jail (it decodes pixels the plugin can read
back from `dst`, which must pass the write jail).
| `pairee.ps.sub(event, fn)` / `pub(event, data)` / `unsub(event)` | Local pub/sub. Callbacks get `(data, meta)`: `meta.from_host` is `true` for host hooks (`on_cd`, `on_hover`, `on_key`, `on_mouse`); for `pub` messages `meta.sender` is the publishing plugin's name and `meta.trusted` its trust, both set by Pairee (a plugin cannot fake them). Untrusted plugins cannot `pub` reserved names (`on_*`, `pairee.*`): it raises an error |
| `pairee.log.info/warn/error/debug` | Host log |
