## Cómo usar este documento

Cada hallazgo tiene un **ID** y una columna **Decisión** vacía. Marcala con:

* `✅ Abordar`: entra en el plan.
* `⏳ Después`: queda para más adelante.
* `❌ No`: se descarta (anotá el motivo).

**Confianza:**

* **A**: verificado leyendo el código. Los marcados con 🔎 los volví a comprobar a mano.
* **M**: muy probable.
* **B**: hay que confirmarlo.

## P0 — Pérdida de datos / seguridad (abordar ya)

|ID|Área|Hallazgo|Escenario|Conf.|Decisión|
|-|-|-|-|-|-|
|FS-01|transfer|**Copiar o mover un archivo sobre sí mismo lo destruye.** No hay ninguna comprobación de `src == dst`. `pipeline.rs` hace `File::create(dst)` sobre el propio origen y, en un Move, después lo borra.|Los dos paneles en la misma carpeta → F5/F6 → Overwrite → el archivo queda en 0 bytes o desaparece.|A 🔎|corregir|
|FS-02|transfer|**La sobrescritura no es atómica.** El destino se trunca antes de copiar. Si hay cancelación, error o se agotan los reintentos, se pierde el original y queda un archivo parcial. Afecta a local (`pipeline.rs:153`), SFTP (`ssh/vfs.rs:112`) y `LocalVfs::write\_file`.|Cancelar a mitad de sobrescribir un archivo grande.|A|corregir|
|FS-03|transfer|**"Verify after copy" no verifica nada.** El hash del destino se calcula sobre el mismo buffer en memoria (`pipeline.rs:184`), sin releer el disco. Además, `verify\_hashes` da `true` con `None` y `verified: true` está fijo.|El usuario confía en una verificación que no ocurre.|A 🔎|corregir|
|FS-04|transfer|**Copiar un symlink hace `chmod 0777` y cambia las fechas del archivo real.** `preserve\_metadata` usa `set\_permissions` y `set\_file\_times`, que siguen el enlace (`metadata.rs:8,32,38`).|Linux: copiar un enlace a `/etc/x` le cambia los permisos al archivo apuntado.|A|corregir|
|FS-05|transfer|**Copiar una carpeta dentro de sí misma no tiene protección, ni hay detección de ciclos de enlaces.** El escáner BFS vuelve a recorrer las carpetas que acaba de crear.|Copiar `A` a `A/sub` → anidamiento infinito hasta `PATH\_MAX`.|A|corregir|
|FS-06|sync|**Sync con `follow\_symlinks` borra fuera del árbol.** Las opciones de copia se aplican también al job de borrado.|Una carpeta-enlace dentro del árbol sincronizado → se borran los archivos de su destino real.|A|corregir|
|FS-07|transfer|**Mover informa éxito aunque no pudo borrar el origen** (`let \_ = remove\_file`, sin `remove\_forcing`).|Windows: origen de solo lectura → queda duplicado.|A|corregir|
|FS-08|transfer|**Enlaces relativos convertidos en absolutos**, y `remove\_dir\_all(dst)` si el destino es una carpeta real (Windows).|Mover un árbol con enlaces relativos → todos quedan rotos. Overwrite de un enlace sobre una carpeta → se borra la carpeta.|A|corregir|
|GIT-01|git|**`pull` y el merge fast-forward hacen `checkout\_head(force())`.**|Hay cambios sin commitear → Pull → se pierden sin aviso.|A 🔎|corregir|
|GIT-02|git|**El merge "normal" pierde el segundo padre.** `commit()` solo usa HEAD como padre y no llama a `cleanup\_state()`. Queda `MERGE\_HEAD`, `CHERRYPICK\_HEAD` o `REVERT\_HEAD`.|El merge se commitea como squash y el CLI de git cree que hay un merge en curso.|A 🔎|corregir|
|GIT-03|git|**Un push rechazado se informa como éxito** (no se usa `push\_update\_reference`).|Push non-fast-forward o a una rama protegida → el usuario cree que hizo push.|A|corregir|
|PLG-01|plugins|**Secure Mode se puede desactivar desde un plugin trusted.** El jail permite escribir en `config\_dir`.|`pairee.fs.write(config.toml, "secure\_mode=false…")`.|A|corregir|
|PLG-02|plugins|**DoS en `pairee.emit`.** `Vec::with\_capacity(max\_index)` con un índice disperso.|`pairee.emit("x", {\[2^60]=1})` → OOM del proceso.|A 🔎|corregir|
|PLG-03|plugins|**El watchdog de CPU se evade con trabajo en C.** El "idle gap" de 50 ms reinicia el presupuesto.|`while true do string.rep("x",1e6) end` no se aborta nunca.|A|corregir|
|PLG-04|plugins|**Secure Mode falla en abierto.** Si `config.toml` no parsea → `secure\_mode=false`.|Un error de sintaxis en la config desactiva el sandbox en silencio.|A|corregir|
|PLG-05|plugins|**La allowlist de comandos se elude por el entorno.** `:env()` no tiene filtro (`GIT\_SSH\_COMMAND`, `LD\_PRELOAD`, `PAGER`…).|`git` permitido + env → ejecución arbitraria.|A|corregir|
|PLG-06|plugins|**`emit` encola cualquier `Action`** (`DeletePermanent`, `Move`…) sin mirar el trust. `cd` tampoco valida la ruta.|Un plugin untrusted borra la selección si `confirm\_delete=false`.|A|corregir|
|CFG-01|config|**Un `keybindings.toml` o un tema inválidos se sustituyen por los valores por defecto** en el siguiente `save()`, sin load-guard. `settings.theme` va a la ruta sin sanear (`../`).|Un error tipográfico en keybindings → se pierden todos los atajos del usuario.|A|corregir|
