# yazi preset — keyboard reference

This page lists the keys the preset ships with; your own changes are not shown here. Press `~` in Pairee for the keyboard shortcuts list, where you can search every key and change it.

- Letters are commands; a letter without a command does nothing.
- A key sequence waits for its next key as long as needed.
