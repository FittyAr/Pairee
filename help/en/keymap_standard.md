# Standard (Explorer, VS Code) preset — keyboard reference

This page lists the keys the preset ships with; your own changes are not shown here. Press `Ctrl+k Ctrl+s` in Pairee for the keyboard shortcuts list, where you can search every key and change it.

- Typing a name jumps to the matching file, as in Explorer.
