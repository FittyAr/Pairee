# Preset Estándar (Explorador, VS Code): referencia de teclas

Esta página lista las teclas con las que viene el preset; tus cambios no aparecen aquí. Pulsa `Ctrl+k Ctrl+s` en Pairee para abrir la lista de atajos, donde puedes buscar cualquier tecla y cambiarla.

- Escribir un nombre salta al archivo que coincide, como en el Explorador.
