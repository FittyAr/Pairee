# Preset yazi: referencia de teclas

Esta página lista las teclas con las que viene el preset; tus cambios no aparecen aquí. Pulsa `~` en Pairee para abrir la lista de atajos, donde puedes buscar cualquier tecla y cambiarla.

- Las letras son comandos; una letra sin comando no hace nada.
- Una secuencia de teclas espera su siguiente tecla todo lo necesario.
