# Preset Capa Vi (compartida por Neovim y yazi): referencia de teclas

Esta página lista las teclas con las que viene el preset; tus cambios no aparecen aquí. Pulsa `Ctrl+k` en Pairee para abrir la lista de atajos, donde puedes buscar cualquier tecla y cambiarla.

- Las letras son comandos; una letra sin comando no hace nada.
